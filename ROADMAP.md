# 🗺️ CoreTex Evolution Track (Roadmap)

Welcome to the development timeline for CoreTex.

We use a **Now / Next / Later** approach to balance immediate needs with long-term goals.

---

## 🚀 NOW (Immediate Pre-Alpha Focus)

### 🔧 Stability & Onboarding
* **File Names:** Make repo structure and naming convention understandable without totally mastering neuroanatomy
* **Stability:** Resolving known cross-platform path initialization and environment bootstrap edge cases inside `./ctx` onboarding routines.
* **Playwright/Sensory Guardrails:** Hardening defensive exception catch gates within the `Sense` submodule to ensure missing system hardware drivers (webcams, audio devices) degrade gracefully without throwing raw Python tracebacks.
* **Feature Stability:** Work out latent issues present in features (particulalry around execution, queuing, and memory)
* **Eval Strategy:** Build an eval system to protect (indeterministic) feature stability

### 🛡️ Core Engine Hardening
* **Code Sandboxing:** Support for Firecracker, Docker, Deno + WASM

---

## 🛰️ NEXT (Near-Term Evolution)

### 💤 Higher Cognitive Daydreaming (Default Mode Network)
* **Autonomous Goal Expansion:** Expanding background `daydream` loops to execute higher-order proactive routines during system rest states.
* **Memory and Identity Enhancements:** Develop novel and higher level aspects of memory and identity, i.e. axiomatic beliefs and ethics.

### 🩸 Ecosystem
* **Integrations:** Telegram, Discord, expansion of webhooks, sockets, fleshing out MCP/ACP, interopability with Hermes, Open Claw, etc.
* **Stable Engram Creation and Reuse:** Ensure 0-cost code reuse is stable and easily injected into development pipelines.

### Core Engine Advancements
* **Distributed Computing:** Allow CoreTex to live and migrate across multiple machines

---

## 🪐 LATER (Long-Term Vision)

### 🧠 ExoCortex Engram Trading and a Gift Economy
* **Inter-Brain Interoperability:** Enabling decentralized communication pathways between completely independent local Brain OS vaults via secure, authenticated ACP/MCP protocols.
* **Hivemind Gift Economy:** Launching a peer-to-peer cognitive barter/gift network where local CoreTex instances can safely share knowledge, engrams, memories, logs, and computing resources natively without centralized corporate silos.
